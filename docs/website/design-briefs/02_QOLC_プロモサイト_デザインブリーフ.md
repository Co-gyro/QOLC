## 1. 目的とゴール

### ビジネス目的
- **介護施設の運営者・事務スタッフ**にQOLCの価値を伝え、資料請求・問い合わせにつなげる
- 副次的に、サービス提供者（訪問診療・薬局等）やご家族にも情報提供

### ターゲット（優先順位順）
1. **介護施設の運営者・事務スタッフ** — 導入の意思決定者
2. **サービス提供者**（訪問診療、薬局、タクシー等）— 施設経由で利用
3. **入居者のご家族** — LINE通知で利用明細を確認する立場

### 競合差別化ポイント
- JCB・セゾン包括加盟店契約（UD独自の強み）
- カード番号非保持・PCI DSS準拠の安全性
- LINEで家族にリアルタイム通知
- 施設の現金集金・立替精算をゼロにする

## 3. ページ構成（トップページ — ワイヤーフレーム準拠）

### ヘッダー（sticky）
- 左: QOLCロゴ（グリーン角丸四角 + テキスト）+ 「QOLC / コルク」
- 右: 「お問い合わせ」ボタン（グリーン）

### ヒーローセクション
- 写真オーバーレイ形式（グリーン系グラデーション）
- バッジ: 「施設の決済業務をまるごとDX」（白半透明ピル型）
- 見出し: 「くらしのお金を **もっとスマート** に」（アクセント = ミントグリーン）
- サブ: 「訪問診療・薬局・タクシーなど / 入居者様の自己負担額をカード自動決済。/ ご家族はLINEで明細を確認できます。」
- CTA: 「資料請求・お問い合わせ →」（白背景、グリーン文字）
- 補足: 「無料 ・ オンライン相談も可能」
- **写真方向性**: 施設内の温かいシーン、スタッフとのやり取り

### サイクルダイアグラム（How it works）
- 見出し: 「三者をつなぎメリットを循環させる」
- SVG図: QOLCを中心に「施設利用者・ご家族」「サービス提供者」「介護施設」が三角に配置
- 矢印ラベル:
  - 施設→利用者: 「LINEでお知らせ / 利用状況をいつでも確認」
  - 利用者→提供者: 「サービスの利用」
  - 提供者→施設: 「利用明細の一元管理 / まとめてアップロード」
- 各ノードにウォームアクセントのベネフィットバッジ:
  - 利用者: 「明細の透明性」「ポイントが貯まる」「現金の手間なし」
  - 提供者: 「未収金ゼロ」「確実な入金」
  - 施設: 「事務工数を大幅削減」「問い合わせ減」
- 最下部メッセージ: 「三者がつながるほど、メリットが循環し拡大する」

### お悩みセクション（Challenges）— 画像+テキスト分割
- 左: 事務作業のイメージ写真
- 右: お悩みリスト（ウォームドット付き）
  1. 毎月の立替精算・現金集金が大変
  2. 請求明細の作成・郵送に時間がかかる
  3. ご家族から「何に使ったの？」と問い合わせが多い
  4. サービス提供者ごとの入金管理が煩雑

### 解決セクション（Solution）— 画像+テキスト分割（反転）
- グリーン淡背景
- 3ステップ（番号円 + テキスト）:
  1. **明細を登録** — CSVアップロード or 手入力
  2. **自動でカード決済** — 登録済みカードで自動引き落とし
  3. **LINEで通知** — ご家族にリアルタイムで明細共有

### 特長セクション（Features）— 交互レイアウト
- 白背景、カード形式（画像左右交互）
  1. **非対面カード決済** — JCB・セゾンなど主要ブランドに対応。カード番号非保持
  2. **LINE通知 & Webポータル** — 決済完了後、ご家族にLINEで自動通知
  3. **セキュリティ万全** — SSL暗号化、USEN PSPの堅牢な決済インフラ
  4. **かんたん導入・専任サポート** — 既存業務を大きく変えず導入OK

### ペルソナ別メリット（Benefits）— タブ切替
- タブ: 施設 / ご家族 / 提供者
- **施設運営者様**:
  - 現金の取り扱い・立替がゼロに
  - 明細作成・郵送コストを大幅削減
  - 入金管理の自動化で事務工数を削減
  - ご家族からの問い合わせが激減
  - 未収リスクがほぼゼロに
- **ご家族様**:
  - LINEで利用明細をリアルタイム確認
  - 何にいくら使ったか一目瞭然
  - スマホから領収書をダウンロード
  - 現金のやり取り・振込の手間なし
  - カードポイントが貯まる
- **サービス提供者様**:
  - 請求・入金がカード決済で確実に
  - 未収金リスクを解消
  - 明細アップロードだけのシンプル運用
  - 管理画面で取引先施設を一元管理

### 数字セクション（Numbers）— 写真背景
- グリーン88%オーバーレイ
- 4つのスタット: 98%（業務削減実感）/ 0円（未収金）/ 24h（明細確認）/ 5分（月次処理）
- ※サービスイン前はイメージ値。ローンチ後に実績値に差し替え

### 料金セクション（Pricing）
- **メインメッセージ**: 初期費用・月額固定費は一切かかりません
- **2カラムバナー**: 「初期費用 0円」「月額固定費 0円」（グリーンペール背景）
- **料金カード**:
  - メイン表示: 「決済手数料 2.5%〜」
  - 料金イメージ（段階制）:
    - 月間決済額 〜100万円: 3.5%
    - 月間決済額 100万〜500万円: 3.0%
    - 月間決済額 500万円〜: 2.5%〜
  - ※ 料率は取引規模・契約内容により変動。詳細はお問い合わせ
- **全プラン共通で含まれるもの**: 管理画面・ポータル利用料 / LINE通知 / 導入サポート / 専任CS
- CTA:「お見積り・お問い合わせ →」

### FAQセクション
- アコーディオン形式
  1. 導入にどのくらい時間がかかりますか？ → 最短2週間
  2. 入居者のカード情報は安全ですか？ → カード番号非保持、PCI DSS準拠
  3. どのクレジットカードに対応していますか？ → JCB、セゾン（Visa/MC）等
  4. 既存の業務フローを変える必要がありますか？ → いいえ、CSV対応
