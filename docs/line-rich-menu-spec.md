公式アカウント「QOLC」(`@388lsozn`) のトーク画面下部に常時表示する**リッチメニュー**の仕様。
各ボタンをタップすると、LINEアプリ内で **LIFF（マイページ）** の該当画面が開く。

> 前提: LIFF ID = `2010492408-6x5mecN4` / LIFF実装は `/liff` で `?next=` による飛び先指定に対応済み。

## 3. デザインガイド（QOLCデザインシステム準拠・高齢者配慮）

- 背景: 白（#FFFFFF）または薄緑（#F0F9F4）
- アイコン・見出し文字: QOLCプライマリ **#4C986A**
- 区切り線: ボーダー色 **#E0DDD8**（セル境界を明確に）
- 文字: **Noto Sans JP**、ボタン文字は**大きめ・太字**（高齢の家族が判別しやすいよう、1セル内で十分な余白）
- アイコンは下記のマイページと統一（Lucideの Home / FileText / Receipt / CreditCard 相当）
- コントラスト比を確保し、装飾過多を避ける（QOLC方針: 独自CSSは最小限・視認性優先）

### バー上部の「メニュー」開閉ラベル（chatBarText）
- 表示テキスト例: **「メニュー」** または **「マイページ」**
- 初期表示: **開いた状態**を推奨（家族が気づきやすい）

## 4. 設定手順（LINE Official Account Manager・コード不要）

1. [LINE Official Account Manager](https://manager.line.biz/) → アカウント「QOLC」を選択
2. **ホーム → リッチメニュー → 作成**
3. 表示設定:
   - タイトル（管理用・ユーザーには非表示）: 例「マイページメニュー」
   - 表示期間: 開始日〜（終了日は空＝無期限）
   - メニューバーのテキスト: **「メニュー」**
   - メニューのデフォルト表示: **表示する**
4. コンテンツ設定:
   - テンプレート: **大（2×3でなく 2×2 の4分割）** を選択
   - 背景画像: 上記仕様で作成した 2500×1686 画像をアップロード
   - 各エリアのアクション: **「リンク」** を選び、§2のURLを貼る（4エリア分）
     - 任意でアクションラベル（音声読み上げ用テキスト）を設定
5. **保存** → 公開
