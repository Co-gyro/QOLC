# セゾン接続情報の扱い — 「申請時要件ではなかった」証拠整理と申請フロー一本化の申し入れ

作成: 2026-09-07 / ユニバーサル・デベロップメント(社内資料・セゾン向け文面ドラフト含む)

## 経緯

2026-09-07、クレディセゾン伊藤氏より「加盟店登録のみでは実際のオーソリ、売上の受け込みはできない」として、
接続情報(センターコード・サブコード・端末識別番号)のメール回答を要求された(初出)。
当社は加盟店申請を様式どおり完了済みであり、申請とは別の個別メール往復が発生する状態は非合理のため、
「申請時に接続情報を含めて提出する」フローへの一本化を申し入れる。

## 当社システム対応(2026-09-07実施)

- QOLC管理画面のセゾンタブで、接続情報票(センターコード/サブコード/端末識別番号/モールコード・店子名入り)を
  申請書と同時に出力できるよう変更。位置づけを「開通後の個別回答」→「申請時同送」に変更
- セゾンから記載列の指定が来た場合は、審査FMTへの直接転記を追加実装する(buildSaisonRowに追記)

### システム反映(2026-09-10実施)

- `buildSaisonRow` が審査FMTの **DQ欄(端末識別番号 POS①)へ端末識別番号を自動転記**
  (「DQ欄にのみ」の指定どおり、DM=端末種類などの他の端末欄は記載しない)
- センターコード/サブコードは全店子共通の固定値のため申請書への記載不要(セゾン側登録済み)
- セゾンタブの「接続情報票(申請時に同送)」ブロックは「接続情報(申請書DQ欄に自動記載)」の
  参照表示に変更(同送は不要になったため。コピーは問い合わせ用に残置)
