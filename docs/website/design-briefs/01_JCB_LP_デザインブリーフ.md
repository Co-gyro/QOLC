## 1. 目的とゴール

### ビジネス目的
- JCBカードホルダー（Wクラス〜Pクラス中心）にDMを送付し、LPへ誘導
- LPのフォームからリード情報を取得し、コンシェルジュが電話でフォローアップ
- 最終的にシニアレジデンスや各種ライフサポートサービスの契約につなげる

### ターゲット
- **主なターゲット**: JCBカードホルダー（50〜70代の子世代）
- **相談対象**: 自分の親、または自分自身の将来の住まい・暮らし
- **カードクラス別ボリューム（4都県）**:
  - Wクラス: 150,756名（33.3%）
  - Gクラス: 142,752名（31.6%）
  - Pクラス: 82,503名（18.3%）
  - Cクラス: 76,085名（16.8%）
- **7都県（静岡・愛知・大阪追加）**: 約72万名
- 上記のうち、JCBプロパーカードのみ（提携カード除外）

### KPI
- DM送付 → LP来訪率
- LP来訪 → フォーム送信率
- フォーム送信 → 電話アポ率
- 電話 → サービス契約率

## 6. 3つのLP デザイン案方針

### 案A: シティホテル・ラウンジ
- **キービジュアル**: ホテルのラウンジで対話するコンシェルジュとお客様
- **トーン**: 暖かみのある高級感。アンバー系の照明が効いた空間
- **カラー比率**: ネイビー70% / ゴールド20% / クリーム10%
- **特徴**: 写真メインで「人のぬくもり」を感じる構成
- **レイアウト**: ヒーローは写真全面オーバーレイ（現ワイヤーフレームに近い）

### 案B: ミニマル・モダンラグジュアリー
- **キービジュアル**: 抽象的な幾何学パターン + テキスト重視
- **トーン**: 洗練されたミニマリズム。余白を贅沢に使う
- **カラー比率**: 白/クリーム60% / ネイビー30% / ゴールド10%
- **特徴**: 写真は控えめ、タイポグラフィとスペーシングで高級感を演出
- **レイアウト**: ヒーローはテキスト+グラデーション背景、写真はセクション内で使用

### 案C: 自然・安らぎ
- **キービジュアル**: 緑豊かなテラスからの眺望、明るく開放的な居住空間
- **トーン**: 自然光、グリーンとゴールドの調和。「安らぎ」を前面に
- **カラー比率**: クリーム/白50% / ネイビー25% / ゴールド15% / グリーンアクセント10%
- **特徴**: 温かみのある写真を大きく使い、「暮らしの安心」を視覚で伝える
- **レイアウト**: セクション交互に写真大+テキスト小のリズム

## 7. 3つのDM デザイン案方針

### DM仕様（6/19・6/23議事録確定事項）
- **形式**: **封筒一択**（6/19議事録で確定）
- **予算**: 約300万円（JCB上土井氏の500万→300万に調整済み）
- **送付数**: 約30,000通（関東4都県W+G中心で調整）
- **コスト目安**: 封書 @130円 × 30,000通 = 約390万 → 予算内に収めるため部数・仕様で調整
- **送付先**: JCBプロパーカード、40歳以上、年間カード利用額300万円以上
- **ターゲットセグメント（6/19議事録）**:
  - 関東4都県: W+G = 42,337名 / W+G+P+C = 56,834名
  - 関東7都県: W+G = 45,645名 / W+G+P+C = 61,692名
- QRコード + 個別ID入りの限定LP URLを記載
- **注意**: 海や山のイメージは避ける（該当レジデンスがない場合クレーム）→ エントランス・共有部分の画像が望ましい

### DM案A: スタンダード封筒（予算最適化）
- **封筒**: 定型封筒、ネイビーの上質紙、ゴールド箔押しでJCBロゴ+「QOLCの安心相談窓口」
- **中身**: A4三つ折りリーフレット（LP内容のサマリ）+ QRカード
- **カラー**: ネイビー×ゴールド、マット加工
- **特徴**: 予算300万に収めつつ開封率を確保。封筒に「JCBカードホルダー様へ 特別なご案内」
- 中身枚数: 2枚（リーフレット + QRカード）

### DM案B: プレミアム封筒（開封率重視）
- **封筒**: 定型封筒、厚手高級紙、ゴールド箔押し+エンボスJCBロゴ
- **中身**: A4見開きリーフレット + パーソナライズドレター（宛名印字）+ QRカード
- **特徴**: パーソナライズで特別感を演出。コストUPだが反応率期待
- 封筒に「◯◯ 様への特別なご案内」とパーソナライズ印字
- 中身枚数: 3枚

### DM案C: コンパクトプレミアム（コスト×品質バランス）
- **封筒**: 洋形封筒（招待状風）、厚手クリーム紙、ゴールドの飾り線
- **中身**: カード型リーフレット（両面フルカラー）+ QRカード
- **特徴**: 「招待状」のように見える封筒で開封率UP。中身は最小限でコスト圧縮
- カード型なので手に取りやすく、シニア層にも見やすい大きな文字
- 中身枚数: 2枚（コンパクト）

## 9. 技術メモ

### フォーム → バックエンド
- フォームは基本的にお客様情報をフォームで取得 → メールまたは電話でフォローの運び
- フォーム回答から「高級レジデンス適合者」と「一般施設紹介対象者（全体の3〜4割）」を判別
- Supabase `jcb_inquiries` テーブルに保存、UD担当者へ自動メール通知

### QRコード・トラッキング
- DM個別ID → LP URLパラメータでDMからの流入を追跡
- JCBセグメント（W/G/P/C）×地域の反応率を計測
