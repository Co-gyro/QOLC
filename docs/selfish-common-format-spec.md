# セルフィッシュ取込 共通フォーマット仕様（確定版 2026-06-23）

JCB・SAISON の振込情報(FI)・振込明細(FM)を**共通フォーマットに変換出力**する。
売上明細(UR)は共通対象外＝各カード会社の生データ（列・行は無加工）。ただし文字コードは Shift-JIS に統一して出力する。

出所の根拠: `振込明細（JCB・SAISON共通フォーマット）20260324_2.xlsx` + UD決定事項 +
`調査資料_回答2.xlsx`（締めサイクル）+ JCB回答（2026/6/22, DLファイルが正・UTF-8 BOM確定）+
セルフィッシュ藤本さん回答（支払区分コード化・変換表）。

## 全体の決定事項（UDで確定）

- **文字コード/改行**: **全出力ファイル（UR / FI / FM、JCB・SAISON共通）を Shift-JIS / CRLF に統一**する。
  - 共通FI/FM は生成時に Shift-JIS でエンコード。
  - URは列・行を無加工で保持しつつ Shift-JIS で出力する（JCB原本はUTF-8(BOM)のため**内容はそのままに文字コードのみShift-JISへ変換**。SAISON原本はShift-JISなので内容維持）。
  - ※「リネームのみ」だった当初仕様から変更。混在を避けるため取込側の想定（Shift-JIS固定）に合わせる。
- **締日**: 15日締めサイクルで**算出**（生データに締日が無いJCBも算出で対応）。
  - 1〜15日売上 → 当月15日締 → 当月末日振込
  - 16〜末日売上 → 当月末日締 → 翌月15日振込
  - 売上日から順算（売上日≤15→当月15日 / ≥16→当月末日）。振込日からは逆算（振込=月末→当月15日 / 振込=翌月15日→前月末日）。
- **手数料率**: **パーセント表記に統一**（例 2.55）。JCBは生値が比率(0.0255)なので **×100**。SAISONはPDF逆算で既に%。
- **加盟店番号(FM)**: **加工しない**。JCB=14桁そのまま / SAISON=加盟店No.(7)＋加盟店店舗No.(7)を連結（単一店舗は同番号のまま `20772472077247`）。
- **支払区分**: **コード＋名称の両方**を出力。SAISONは下記変換表で名称→コード。
- **集計日(FM)**: 列を持つ。値＝**売上日**（JCB:売上年月日 / SAISON:受付日）。修正・再処理の基準。

## 売上明細 UR（共通対象外・列/行は無加工。文字コードはShift-JISに統一）
- JCB=`sales_details-*.csv`（原本はUTF-8 BOM/CRLF →**Shift-JISに変換して出力**, 伝票番号は空。一意キーは**売上票照会コード**または承認番号）
- SAISON=売上データCSV（原本Shift-JIS, 伝票番号あり）
- ※ 出力は全ファイル Shift-JIS / CRLF に統一（UTF-8混在を解消）。
